# 같이 놀자

차 안처럼 심심한 공간에서 아이들과 시간을 보내라고 만든 **놀이 친구 웹앱**.
앱이 말을 걸며 퀴즈를 내고, 끝말잇기를 하고, 이야기를 들려주고, 간단한 영어도 알려 줍니다.
인터넷도 PC도 없이 폰/태블릿만으로 돌아갑니다.

## 듣기 모드 (기본값)

차에서는 아이들이 화면을 보지 않고 **귀로만** 풀 수 있어야 하므로, 기본이 듣기 모드입니다.

- 문제도 보기도 전부 소리로 읽어 줍니다 — "1번 돼지, 2번 고양이, 3번 개구리"처럼 번호와 함께.
- 화면을 봐야 푸는 문제(색깔 고르기, 그림 세기 등)는 듣기 모드에서 아예 나오지 않습니다.
- 아무도 화면을 안 볼 때를 위해 **🙉 정답 알려줘** 버튼이 있습니다. 누르면 정답을 말해 주고,
  "맞혔어!"를 누르면 별을 받습니다. 아이는 소리 듣고 대답만 하면 됩니다.
- 집에서 그림 문제도 같이 보고 싶으면 **🎪 놀이 바꾸기 → 👀 화면 모드**로 바꿀 수 있습니다.

## 말로 대답하기 (대화 모드)

아이가 화면을 누르지 않고 **소리로 대답**할 수 있습니다.
앱이 문제와 보기를 다 읽어 준 뒤 "🎙️ 듣고 있어…"가 뜨면, 그때 아이가 답을 말하면 됩니다.

- 켜는 곳: **🎪 놀이 바꾸기 → 🎙️ 말로 대답하기**. 처음 켤 때 마이크 사용을 허용해야 합니다.
- 알아듣는 말: 보기 그대로("돼지"), 번호로("3번", "세 번째"),
  숫자는 읽는 법 아무거나("12" = "십이" = "열둘"), 단위 생략("다섯 개" → "다섯")
- 못 알아들으면 한 번 더 물어보고, 그래도 안 되면 화면을 눌러 답하면 됩니다. 손으로 누르는 길은 항상 열려 있습니다.
- **인터넷이 필요합니다.** 음성 인식은 기기가 아니라 애플/구글 서버가 하기 때문에, 터널처럼
  신호가 끊기는 곳에서는 동작하지 않습니다. 이때는 화면을 눌러 답하면 됩니다(문제는 오프라인에서도 계속 나옵니다).

## 무슨 놀이를 하나

앱이 진행을 이끌면서 아래를 번갈아 내놓습니다.

| 놀이 | 내용 |
| --- | --- |
| 퀴즈 | 동물 소리, 수수께끼, 반대말, 우리말로 세기, 덧셈·뺄셈, 수 나열, 상식 (나이별) |
| 끝말잇기 | 앱이 낱말을 말하면 이어지는 말을 보기 셋 중에서 고르기. 번갈아 주고받습니다 |
| 이야기 듣기 | 짧은 창작 동화 6편. 조각씩 읽어 주고, 끝에 질문과 "같이 이야기해 보기" |
| 영어 놀이 | 영어 듣고 뜻 맞히기, 우리말 듣고 영어 맞히기, 따라 말하기 |

나이별로 난이도가 갈립니다. 4세는 소리·수수께끼 위주, 6세는 10까지 셈, 9세는 큰 수 계산까지.

## 시작하는 방법

- **바로 시작하기** — 아무것도 입력하지 않고 바로 놀기 ("다같이" 모드)
- **이름 알려주고 시작하기** — 인원 수 → 이름·나이 입력. 이름을 부르며 차례를 돌리고 각자 나이에 맞게 냅니다
- **지난번 친구들로 시작** — 한 번 입력하면 저장되어 다음부터 한 번에 시작

## 폰에서 쓰는 방법

### 방법 1. 주소로 열고 홈 화면에 추가 (아이폰은 이 방법)

**https://greenenergy0.github.io/kids-quiz/**

1. 아이폰 **사파리**에서 위 주소 열기 (크롬 말고 사파리)
2. 아래 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 한 번 실행 → 이후 비행기 모드에서도 돌아갑니다

안드로이드는 크롬에서 열고 메뉴 → "앱 설치"를 누르면 같습니다.

### 방법 2. 파일 하나로 (안드로이드에서 간편)

`dist/kidsplay.html` — 앱 전체가 들어 있는 파일 한 개입니다. 폰에 보내서 열면 그대로 돌아갑니다.
아이폰은 로컬 HTML 파일 실행을 막는 경우가 많아 방법 1을 쓰세요.

```
python build_single.py
```

## 구조

```
kids_quiz/
├─ index.html              화면 뼈대 + 서비스워커 등록
├─ manifest.webmanifest    앱 이름·아이콘·전체화면 설정
├─ sw.js                   오프라인 캐시
├─ build_single.py         전체를 파일 하나로 합치는 빌드
├─ dist/kidsplay.html      합쳐진 결과물 (폰에 보내는 용)
├─ icons/                  앱 아이콘
├─ css/style.css           스타일 (웹폰트 없이 시스템 글꼴 — 오프라인 대비)
└─ js/
   ├─ app.js               놀이 진행(화면 전환·차례·별 모으기)
   ├─ listen.js            듣기 전용 문제 (소리·수수께끼·반대말·셈)
   ├─ mic.js               말로 대답하기 (음성 인식 + 말 알아듣기)
   ├─ questions.js         화면 모드용 문제 생성기
   ├─ quiz.js              상식 문제 은행 (QUESTION_BANK)
   ├─ words.js             끝말잇기 낱말 사전
   ├─ stories.js           이야기
   ├─ english.js           영어 놀이
   └─ speech.js            음성 안내(한국어/영어)
```

`app.js`만 화면을 그리고, 나머지는 화면과 무관한 데이터·로직입니다.
앱으로 포팅할 때 `speech.js`만 네이티브 TTS로 바꾸면 나머지는 그대로 씁니다.

## 내용 추가하기

- **상식 문제**: `js/quiz.js`의 `QUESTION_BANK`에 `{ age, question, choices, answer }`
- **수수께끼·반대말·동물 소리**: `js/listen.js`의 `RIDDLES` / `OPPOSITES` / `ANIMAL_SOUNDS`
- **끝말잇기 낱말**: `js/words.js`의 `WORD_CHAIN` (끝 글자로 시작하는 말이 여럿 있어야 잘 이어집니다)
- **이야기**: `js/stories.js`에 `{ title, emoji, segments, question, talk }`
- **영어 단어**: `js/english.js`의 `EN_WORDS`에 `{ emoji, ko, en }`
- **놀이 순서**: `js/app.js`의 `CYCLE` 배열

### 내용을 고친 뒤에는

1. `sw.js` 첫 줄 `kidsquiz-v7`의 숫자를 올립니다 (안 올리면 폰이 옛 버전을 계속 씁니다)
2. `python build_single.py` (파일 버전도 갱신)
3. `git add -A && git commit -m "..." && git push`

푸시하면 1~2분 뒤 GitHub Pages에 반영되고, 설치된 앱은 완전히 닫았다 다시 열 때 새 버전이 적용됩니다.

## 목소리를 사람 목소리처럼 만들기

앱은 브라우저가 기기에 설치된 음성을 씁니다. 그래서 **기기에 좋은 음성이 깔려 있는지가
가장 큰 차이**를 만듭니다. 기본으로 깔린 옛날 음성은 아무리 다듬어도 기계음처럼 들립니다.

- **아이폰**: 설정 → 손쉬운 사용 → 콘텐츠 말하기 → 음성 → 한국어 → **유나(고품질/프리미엄)** 내려받기.
  영어도 같이 받아 두면 영어 놀이가 자연스러워집니다.
- **안드로이드**: 설정 → 접근성 → 텍스트 음성 변환(TTS) → Google 음성 서비스 →
  음성 데이터 설치 → **한국어**(고품질 항목이 있으면 그걸로).

받은 뒤 앱에서 **🎪 놀이 바꾸기 → 🎤 목소리 고르기**에서 들어보고 마음에 드는 걸 고르면 됩니다.
고른 목소리는 기억해 뒀다가 다음에도 씁니다.

앱 쪽에서도 사람처럼 들리도록 이렇게 해 뒀습니다.

- 기기에 있는 음성 중 고품질(프리미엄/향상/자연음) 음성을 자동으로 먼저 고릅니다
- 긴 문장은 마침표에서 끊어 읽어 한 호흡에 쏟아내지 않습니다
- 상황에 따라 말 속도와 높낮이를 바꿉니다 (이야기는 천천히, 칭찬은 밝게, 위로는 부드럽게)
- 칭찬과 위로는 매번 다른 말로 하고, 가끔 아이 이름을 불러 줍니다
- 이모지는 읽지 않습니다 ("🎉"를 "파티 폭죽"이라고 읽던 문제)

## 알아둘 점

- 놀고 있는 동안 화면이 자동으로 꺼지지 않게 해 둡니다(지원 기기 한정).
- 소리는 오른쪽 아래 🔊 버튼으로 끌 수 있습니다.
